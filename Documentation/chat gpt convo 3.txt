ABSTRACT

Urban transportation in many developing regions still relies heavily on traditional auto-rickshaw services. While these services are essential for daily commuting, they often suffer from several challenges such as inefficient ride matching, lack of fare transparency, limited digital assistance for drivers, and safety concerns for passengers. With the increasing adoption of mobile technologies, there exists a strong opportunity to develop digital systems that can improve the efficiency, accessibility, and reliability of local transport services.

This case study presents RIKSahyak, a smart ride assistance platform designed to support the auto-rickshaw transportation ecosystem by providing a digital interface for passengers, drivers, and administrators. The system aims to simplify ride booking, improve driver-passenger communication, and enhance transparency in fare estimation and ride management. RIKSahyak is developed as a mobile-based solution using React Native and Expo for the frontend, while the backend services are implemented using FastAPI, a high-performance Python framework for building asynchronous APIs. The system utilizes Firebase Firestore as its cloud database to manage user data, ride information, and system records.

The platform integrates several important features such as real-time ride request handling, driver matching based on geographical proximity, fare estimation using distance-based algorithms, and live ride tracking through map services. The backend architecture is designed using asynchronous programming techniques to ensure efficient request handling and improved system performance. In addition, various RESTful APIs were developed to facilitate communication between the mobile application and the server.

The project also includes testing and validation of core system functionalities such as ride creation, driver assignment, fare calculation, and API response performance. A performance optimization case was identified during development where blocking network calls affected the system’s asynchronous event loop. This issue was resolved by replacing synchronous requests with asynchronous HTTP clients, significantly improving system responsiveness and scalability.

The RIKSahyak platform was also demonstrated as part of an innovation-focused project initiative, showcasing the potential of the system to support local transportation services through technology-driven solutions. The system demonstrates how software engineering principles such as requirement analysis, system design, modular architecture, and performance optimization can be applied to develop a practical and scalable transportation assistance platform.

Overall, this case study highlights the design, development, and evaluation of a technology-driven approach aimed at improving the efficiency and accessibility of auto-rickshaw transportation systems.

Chapter 1
Introduction
1.1 Background
Urban transportation plays a crucial role in supporting the daily mobility needs of people, particularly in developing countries where public transportation infrastructure is still evolving. In many Indian cities and towns, auto-rickshaws serve as one of the most accessible and affordable modes of short-distance transportation. They provide last-mile connectivity and are widely used by commuters for daily travel, connecting residential areas with markets, educational institutions, offices, and transport hubs.

Despite their importance, the traditional auto-rickshaw transportation system still operates largely through manual processes. Passengers often face difficulties such as uncertain fare estimation, difficulty in finding available drivers, lack of transparency in pricing, and limited digital support for booking rides. Similarly, drivers often face challenges in identifying nearby passengers efficiently, managing ride requests, and accessing technological tools that could help improve their productivity.

With the rapid growth of mobile technologies, cloud computing, and location-based services, digital platforms have transformed several sectors of transportation. Ride-hailing applications have introduced structured systems for booking, tracking, and managing rides. 5.5 Algorithms Used
Several algorithms are used to ensure efficient ride allocation and accurate fare calculation.

Driver Matching Algorithm
The driver matching algorithm finds the nearest available driver to the passenger’s pickup location. It calculates distances between drivers and the passenger and selects the driver with the minimum distance.

Steps involved:

Retrieve list of available drivers

Calculate distance between passenger and each driver

Sort drivers by distance

Assign the closest driver

Fare Calculation Algorithm
The fare is calculated based on distance traveled and base fare.

Basic formula:

Fare = Base Fare + (Distance × Rate per km)
Additional factors such as waiting time or surge pricing can also be incorporated.

Distance Calculation
Distance between two geographical coordinates is calculated using the Haversine Formula, which determines the shortest distance between two points on Earth.

Formula:

d = 2r * arcsin( √(sin²((lat2-lat1)/2) + cos(lat1) * cos(lat2) * sin²((lon2-lon1)/2)) )
Where:

r is the Earth's radius

lat1, lon1 are pickup coordinates

lat2, lon2 are driver coordinates
