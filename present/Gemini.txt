Step 1: System Initialization (The Start of the Day)

Location: Bus Depot / Time: 05:30 AM



Admin Dashboard: The Depot Manager logs into the Admin Panel (Django Web App). They see the map of Maharashtra, currently empty. They click "Assign Shift."

ETM App: Conductor Rahul opens the React Native App on his device. He enters his ID.



Interaction: The ETM app sends a GET request to the Backend: Is there a shift for Rahul?



Response: Backend sends back the Route details, Stops, and Fare Table. The ETM app is now "Locked" to Route 101.

Location: Commuter’s Home / Time: 07:00 AM



User App: A passenger, Priya, opens the User App. She searches for "Hinjewadi."



The Interaction:
